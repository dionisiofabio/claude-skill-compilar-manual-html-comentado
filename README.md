# compilar-manual-html-comentado

Variante **comentada** de `compilar-manual-html`: além de compilar o material-fonte
num manual HTML autocontido, a IA acrescenta uma camada própria de **apontamentos**
(complementos, insights, dicas e — sobretudo — **atualizações** e **correções**
datadas e com fonte), sempre em blocos visualmente separados (violeta) do que o
curso ensinou.

Arquivo principal: `SKILL.md`.
- `assets/template.html` — esqueleto com CSS/JS (já traz o CSS da camada-IA).
- `references/componentes.md` — catálogo de blocos (inclui o componente Apontamento da IA e o Índice de apontamentos).
